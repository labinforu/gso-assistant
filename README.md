# ГСО-Ассистент (GSO Assistant)

![ГСО-Ассистент — логотип программы](assets/gso-assistant-logo.svg)

**ГСО-Ассистент** — бесплатная локальная программа Lab-Info для учёта стандартных образцов в испытательных лабораториях. Она помогает учитывать **ГСО, СОП, зарубежные и другие стандартные образцы**, регистрировать их фактические партии, хранить паспорта и сопроводительные документы, получать доступные сведения из ФГИС «Аршин» и готовить **форму 5**.

> **Текущий выпуск:** [0.3.0 Beta 1](https://github.com/labinforu/gso-assistant/releases/tag/v0.3.0-beta1) — предварительная версия (**Pre-release**) для Windows 10/11 x64. Собственный исходный код программы в репозитории не публикуется.

## Основные возможности

- **Реестр СО и их партий.** Одна фактическая партия учитывается отдельно от сведений о типе стандартного образца.
- **Несколько категорий.** ГСО из ФГИС «Аршин», СОП, зарубежные и иные СО, которых может не быть в «Аршине».
- **Связь с «Аршином».** Поиск и получение доступной информации о типах ГСО через публичные интерфейсы.
- **Документы.** Локальное хранение паспортов конкретных партий, сопроводительной документации и пользовательских шаблонов.
- **Форма 5.** Импорт и подготовка документов, в первую очередь из Word DOCX, с проверкой результата пользователем.
- **Резервные копии.** Создание ZIP-копии, восстановление и завершение программы непосредственно через браузер.

## Как запускается

Запустите установленную программу через ярлык. Локальный сервер откроет рабочий интерфейс **сразу в браузере**, без дополнительного окна управления. Обычно адрес — `http://127.0.0.1:8765/`; если этот порт занят, приложение автоматически выберет следующий свободный. Повторный запуск ярлыка открывает уже работающий экземпляр.

**Закрытие вкладки не завершает программу.** Для полного выхода используйте раздел «Управление программой» или ярлык завершения из меню «Пуск».

## Данные остаются на Вашем компьютере

Рабочие данные, вложения и шаблоны находятся в каталоге:

```text
%LOCALAPPDATA%\Lab-Info\GSO_Assistant_2
```

Для локального учёта интернет не требуется. Для запросов во ФГИС «Аршин» необходимо сетевое соединение. При обновлении не удаляйте папку с данными, а резервные копии храните отдельно от рабочего ПК.

## Ограничения Beta 1

Это **предварительная версия** для ознакомления и тестирования. Возможны ошибки и ограничения совместимости.

- Сведения **о типе ГСО** из «Аршина» **не заменяют паспорт конкретной партии** и её фактические аттестованные значения.
- Сканированные PDF без текстового слоя не распознаются автоматически; для структурированного импорта формы 5 предпочтительны DOCX.
- Перед использованием результатов в документах лаборатории ответственный специалист проверяет значения, сроки, пригодность СО и корректность заполнения формы 5.
- ГСО-Ассистент — независимая программа, **не являющаяся официальным продуктом** ФГИС «Аршин», Росстандарта или Росаккредитации.
