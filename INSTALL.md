# Установка ГСО-Ассистента 0.3.0 Beta 1

## Системные требования

- Windows 10 версии 1809 или новее либо Windows 11, 64-бит.
- Установленный веб-браузер.
- Возможность запуска локального приложения на `127.0.0.1`.
- Интернет для поиска сведений ФГИС «Аршин» (для локального учёта не обязателен).

**Python и дополнительные библиотеки устанавливать не нужно.**

## Скачивание и установка

1. Откройте [Releases](https://github.com/labinforu/gso-assistant/releases) и найдите предварительный выпуск **v0.3.0-beta1** (после его публикации).
2. В разделе **Assets** скачайте файл `GSOAssistant_0.3.0-beta1_Setup.exe`.
3. Для проверки подлинности вычислите SHA-256 в PowerShell:

   ```powershell
   Get-FileHash "$env:USERPROFILE\Downloads\GSOAssistant_0.3.0-beta1_Setup.exe" -Algorithm SHA256
   ```

   Ожидаемый хеш подготовленного установщика: `f524ea8eca73ee8a43ab5211817d1f74a9fdb1c92fbcde6f66b3d2ad6758759e`. Если файл переиздан, сравнивайте его хеш с контрольной суммой именно этого выпуска.

4. Запустите установщик и ознакомьтесь с лицензионным соглашением.
5. После завершения установки запустите **«ГСО-Ассистент»** из меню «Пуск» или с ярлыка рабочего стола (если Вы создали его при установке).

## Первый запуск

Программа автоматически запустит локальный сервер и откроет интерфейс в Вашем браузере. Обычно используется `http://127.0.0.1:8765/`. При занятости 8765 будет выбран другой свободный порт; вручную менять его не требуется.

Если программа уже работает, повторный запуск ярлыка открывает её существующий экземпляр. Закрытие вкладки браузера **не** останавливает локальный сервер. Для полного выхода откройте **«Управление программой» → «Завершить программу»** или используйте отдельный ярлык завершения в меню «Пуск».

## Обновление и резервные копии

Перед обновлением скачайте резервную копию через раздел **«Управление программой»** и сохраните ZIP отдельно от компьютера.

Каталог пользовательских данных:

```text
%LOCALAPPDATA%\Lab-Info\GSO_Assistant_2
```

Не удаляйте его при обновлении и не прикрепляйте к публичным GitHub Issues.

## Если программа не запускается

1. Попробуйте повторно открыть программу через ярлык; она может уже работать в фоне.
2. Проверьте, что Windows не блокирует запуск, и что установлен браузер.
3. Проверьте локальный журнал `%LOCALAPPDATA%\Lab-Info\GSO_Assistant_2\startup_errors.log`.
4. Сообщите о проблеме в [Issues](https://github.com/labinforu/gso-assistant/issues/new/choose) или по адресу **aas@lab-info.ru**. Перед отправкой удалите персональные данные, пути с именами сотрудников и содержимое документов.

**Внимание:** 0.3.0 Beta 1 — предварительный выпуск. Перед использованием на рабочих данных рекомендуется проверить функции на тестовой базе.
