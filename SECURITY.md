# Безопасность и сообщения об уязвимостях

Об ошибках, которые могут привести к утрате данных, раскрытию документов или несанкционированному доступу, сообщайте **на aas@lab-info.ru**.

**Не публикуйте описание способа эксплуатации уязвимости, рабочие базы, паспорта партий, персональные данные, пароли и внутреннюю документацию лаборатории в открытых GitHub Issues.** Согласуйте безопасный канал передачи материалов с разработчиком.

При обращении укажите версию ГСО-Ассистента, версию Windows и шаги воспроизведения без конфиденциальной информации. Для обычных вопросов используйте [Issues](https://github.com/labinforu/gso-assistant/issues/new/choose).

Обновления и исправления публикуются в разделе [Releases](https://github.com/labinforu/gso-assistant/releases) по мере готовности; предварительный выпуск не предполагает гарантированных сроков поддержки.

Локальная база не должна размещаться в общедоступных папках и публичных облачных ссылках. Сохраняйте резервные копии в защищённом месте.
