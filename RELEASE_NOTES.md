# ГСО-Ассистент 0.3.0 Beta 1 — первый предварительный выпуск

**ГСО-Ассистент** — бесплатная локальная программа Lab-Info для учёта стандартных образцов в испытательных лабораториях: ГСО, СОП, зарубежных и других СО.

## Основные возможности

- Учёт стандартных образцов и фактических партий с раздельным хранением сведений о типе и партии.
- Поиск и получение доступных данных о типах ГСО через ФГИС «Аршин».
- Хранение паспортов партий и дополнительных документов локально.
- Работа с формой 5 и Word DOCX.
- Работа в браузере через локальный сервер, без дополнительного окна.
- Автоматическое определение свободного порта, повторное открытие работающей копии.
- Резервное копирование, восстановление и завершение работы из веб-интерфейса.

## Установка

1. Скачайте из **Assets** файл `GSOAssistant_0.3.0-beta1_Setup.exe` и файл контрольной суммы `SHA256SUMS.txt` (или вариант `.sha256` с соответствующим именем).
2. Проверьте SHA-256: `f524ea8eca73ee8a43ab5211817d1f74a9fdb1c92fbcde6f66b3d2ad6758759e`.
3. Запустите установщик на Windows 10/11 x64 и примите пользовательское соглашение.
4. После установки запустите программу из меню «Пуск» — интерфейс автоматически откроется в браузере. Python устанавливать не требуется.

## Важная информация

Это **предварительный выпуск (Pre-release)**. Программа не является официальным продуктом ФГИС «Аршин», Росстандарта или Росаккредитации. Сведения о типе ГСО не заменяют паспорт конкретной партии. Форму 5 и метрологические сведения перед использованием проверяет ответственный сотрудник лаборатории.

Данные сохраняются локально: `%LOCALAPPDATA%\Lab-Info\GSO_Assistant_2`. При обновлении папку данных не удаляйте, резервные копии храните отдельно.

**Лицензия:** бесплатно для внутреннего использования, включая деятельность испытательных лабораторий; собственный исходный код не публикуется.
